Cobotics

An interactive CLI that reasons over robots, sensors, and actuators — with a built-in simulator so it runs with no real hardware, and an NVIDIA Nemotron backend served by Nebius Token Factory.

View on GitHub Get started

What it does

Hybrid command interface

Slash-commands (/move, /sensors, /grip) and plain natural language in the same prompt.

Built-in simulator

Position, battery, and range sensors plus drive and gripper actuators — no physical hardware required.

Nemotron reasoning

Natural-language turns answered by an NVIDIA Nemotron model through Nebius Token Factory's OpenAI-compatible API.

Pluggable backends

Offline stub by default; Nebius, OpenAI, and Anthropic are opt-in behind one interface.

Swappable hardware layer

Clean Sensor/Actuator abstractions — drop in real drivers without touching the rest.

Config-driven

Environment and .env via pydantic-settings, with sensible defaults.

Powered by NVIDIA + Nebius

Cobotics runs its intelligence on sponsor infrastructure end to end — the embodied loop is SENSE → REASON → ACT.

SENSE
perception pipeline reads the sensors
→
REASON
NVIDIA Nemotron on Nebius Token Factory
→
ACT
motion planner drives the actuators

NVIDIA Nemotron

The open-source model powering the agent's reasoning. Every natural-language turn is answered by Nemotron with live sensor context.

Nebius Token Factory

Serves Nemotron through an OpenAI-compatible inference API. The live agent makes its runtime calls here.

Nebius Serverless Jobs

A batch worker processes simulated sensor data at scale and summarizes it with Nemotron — runs locally and, unchanged, as a Serverless Job.

Install

python -m venv .venv
.venv\Scripts\activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -e .

Optional backends: pip install -e ".[nebius]" (Nebius Token Factory + NVIDIA Nemotron), ".[openai]", ".[anthropic]", ".[dev]" for tests.

Run

cobotics            # launch Cobotics
# or without installing:
python -m cobotics
CommandDescription
/helpShow available commands
/statusShow registered devices and world state
/sensorsRead all sensors
/move <x> <y>Move the robot to a target position
/grip open|closeOperate the gripper
/resetReset the simulator
/exit, /quitExit Cobotics

Anything that isn't a slash-command is treated as natural language and routed to the AI agent.

Nebius Token Factory (NVIDIA Nemotron)

Point Cobotics at a Nemotron model served by Nebius Token Factory:

COBOTICS_AI_BACKEND=nebius
NEBIUS_API_KEY=your-token-factory-key
COBOTICS_AI_MODEL=nvidia/Llama-3_3-Nemotron-Super-49B-v1
COBOTICS_NEBIUS_BASE_URL=https://api.studio.nebius.com/v1/

Token Factory exposes an OpenAI-compatible chat completions API, so the nebius backend reaches it through the OpenAI SDK with live sensor context injected by the perception pipeline.
